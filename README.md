## 🇬🇧 English Documentation

### ✨ Features
- **Quick Switch:** Easily toggle between SOCKS4, SOCKS5, HTTP, and HTTPS protocols.
- **Smart Presets:** One-click tags to auto-fill common local IPs (Localhost, Android Hotspot `192.168.43.1`) and default ports (`10808`, `10809`).
- **Profile Management:** Save your favorite configurations and load them instantly from a dropdown menu.
- **Auto Ping Test:** Built-in lightweight latency checker to ensure your proxy is active.
- **Collapsible Auth:** Clean UI that hides Username/Password fields until you need them.
- **🛡️ Privacy-Focused & 100% Local:** Zero tracking or telemetry. All your proxy profiles and credentials are saved strictly on your browser's local storage (`chrome.storage.local`). The code is entirely open-source and transparent.

### 🚀 How to Install
Since this extension is manually distributed, follow these steps to install:
1. Download the latest `Proxy-Manager.zip` from the **[Releases](../../releases)** page.
2. Extract the `.zip` file into a folder on your computer.
3. Open Google Chrome and navigate to `chrome://extensions/`.
4. Turn on **"Developer mode"** (toggle switch in the top right).
5. Click on **"Load unpacked"** and select the extracted folder.
6. Pin the extension to your toolbar!

## 🇮🇷 راهنمای فارسی

### ✨ ویژگی‌های کلیدی
- **سوییچ سریع:** تغییر لحظه‌ای بین پروتکل‌های SOCKS4, SOCKS5, HTTP و HTTPS.
- **تگ‌های سریع (Presets):** وارد کردن خودکار آی‌پی‌های پرکاربرد (مثل لوکال‌هاست یا هات‌اسپات اندروید `192.168.43.1`) و پورت‌های دیفالت (مثل `10808`) تنها با یک کلیک.
- **مدیریت پروفایل‌ها:** ذخیره کانفیگ‌های دلخواه و فراخوانی سریع آن‌ها از طریق منوی کشویی.
- **تست پینگ خودکار:** سنجش لحظه‌ای پینگ برای اطمینان از متصل بودن پراکسی.
- **طراحی مینیمال:** پنهان‌سازی هوشمند فیلدهای یوزرنیم و پسورد برای خلوت ماندن رابط کاربری.
- **🛡️ حریم خصوصی و کاملاً لوکال:** بدون هیچ‌گونه سیستم ردگیری (Zero Tracking). تمام داده‌های شما منحصراً روی حافظه محلی مرورگر ذخیره می‌شوند و هیچ فایلی به سرور خارجی ارسال نمی‌شود. پروژه‌ای کاملاً متن‌باز و شفاف برای امنیت کامل شما.

### 🚀 آموزش نصب افزونه
برای نصب دستی افزونه در مرورگر کروم، مراحل زیر را طی کنید:
1. جدیدترین فایل `Proxy-Manager.zip` را از بخش **[Releases](../../releases)** دانلود کنید.
2. فایل زیپ را در یک پوشه استخراج (Extract) کنید.
3. مرورگر کروم را باز کرده و به آدرس `chrome://extensions/` بروید.
4. از گوشه بالا سمت راست، گزینه **"Developer mode"** را روشن کنید.
5. از بالا سمت چپ روی دکمه **"Load unpacked"** کلیک کرده و پوشه‌ای که استخراج کردید را انتخاب کنید.
6. افزونه را در نوار بالای مرورگر پین (Pin) کنید و از آن لذت ببرید!
